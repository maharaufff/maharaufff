###  Featured Projects

<details>
<summary><b>DropSpot3D</b> — WebMCP-based automobile defect detection</summary>

Turns a video or photos of a car into a 3D model. A browser-based AI agent, connected via WebMCP, can be told in plain text where a defect is (or shown a photo of one) — it locates that exact point on the 3D model, pins it, and generates a report.

| | |
|---|---|
| **Stack** | WebMCP, AI Agents, 3D Vision |
| **Context** | Built for the OpenAI WebMCP Hackathon |
| **Repository** | [github.com/maharaufff](https://github.com/maharaufff) |

</details>

<details>
<summary><b>AI Document Assistant (ai_chatbot)</b> — face-authenticated RAG assistant</summary>

A face-authenticated document assistant built during an internship. Users upload documents, ask questions, keep chat history, and interact by voice.

| | |
|---|---|
| **Stack** | Python, Streamlit, FAISS, Groq, RAG, SQLite, Face Recognition, Voice AI |

| **Repository** | [github.com/maharaufff](https://github.com/maharaufff) |

</details>
